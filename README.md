# Tic-Tac-Toe Game

## Project Description
Tic-Tac-Toe is a simple two-player console-based game developed using C++. Players take turns marking X and O on a 3×3 board. The first player to complete a row, column, or diagonal wins the game.

## Features
- Two-player gameplay.
- 3×3 game board.
- Automatic winner detection.
- Draw detection.
- Position validation.
- Alternating player turns.

## Technologies Used
- Programming Language: C++
- Concepts: Arrays, Functions, Loops, Conditional Statements and Basic Game Logic.

## Files Included
- `TicTacToe.cpp` – Main game source code.

## How to Run
1. Open the code in VS Code or any C++ compiler.
2. Compile and run the program.
3. Enter positions from 1 to 9.
4. Players take turns until someone wins or the game ends in a draw.

## Conclusion
This project demonstrates the use of fundamental C++ programming concepts to develop an interactive two-player game.
